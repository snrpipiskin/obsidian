# Примеры резюме Go-разработчиков

## Пример 1. E-commerce & B2B (Опыт ~4 года)

### Место работы: SELDON (1 год 9 месяцев)
**Сферы проекта:** Услуги для бизнеса, E-commerce, ИТ-решения
**Должность:** Golang-разработчик

**Контекст проекта:**
Разработка микросервисной архитектуры для e-com платформы интернет-магазина (более 4 млн активных пользователей). Работа в кросс-функциональной команде из 6 человек (3 Go-разработчика, 2 QA, аналитик). Выстроены DevOps-процессы, CI/CD, регламенты Code Review.

**Обязанности:**
Разработка сервиса контроля доступа для селлеров (RBAC), модуля выгрузки аналитических отчетов и системы управления закупками.

**Стек технологий:**
Go, PostgreSQL, ClickHouse, Redis, Kafka, Kubernetes, Docker, Helm, gRPC, Prometheus, Grafana, GitLab CI.

**Достижения:**
- Реорганизовал архитектуру бэкенд-сервисов с внедрением Kubernetes и централизованного логирования, что обеспечило отказоустойчивость контура оформления заказов при пиковых нагрузках.
- Спроектировал API-гейтвей для управления задачами на базе Clean Architecture с автоматической кодогенерацией контрактов.
- Оптимизировал работу микросервиса потоковой генерации Excel-отчетов с применением профилировщика `pprof` (устранены утечки памяти при экспорте массивов данных).
- Реализовал конвейер пакетной обработки сообщений в Kafka для асинхронного обновления статусов заказов и синхронизации каталогов товаров.

### Место работы: AxGrid (2 года 5 месяцев)
**Сферы проекта:** Системная интеграция, Логистика
**Должность:** Golang developer

**Контекст проекта:**
Автоматизация B2B-процессов корпоративных клиентов с нагрузкой на контуре до 100 000 транзакций в неделю. Ответственность за проектирование сервисов аналитики вызовов и управления заказами в команде из 3 разработчиков на Go.

**Достижения:**
- Реализовал асинхронную шину событий на базе Kafka, что позволило масштабировать обработку уведомлений до 30 000 сообщений в минуту.
- Снизил p95 latency API на 30%, настроив составные индексы в PostgreSQL и интегрировав мониторинг Prometheus под нагрузкой 20k RPS.
- Разработал телеграм-клиент для административного управления торговыми точками (использование Redis для сессий, PostgreSQL для хранения данных), охватывающий 35 000 активных сессий.

## Пример 2. Промышленный IoT / Infrastructure (Опыт 2.5 года)

**Сфера проекта:** Информационные технологии, Промышленный сектор
**Должность:** Golang Developer

**Обязанности:**
Проектирование распределенных отказоустойчивых систем анализа телеметрических данных в домене промышленного IoT. Разработка REST API, внедрение архитектурных стандартов в команде.

**Достижения:**
- Спроектировал микросервис сбора телеметрии с буровых установок (concurrency pattern "Fan-in" через goroutines/channels), обрабатывающий потоки от сотен оборудования в режиме реального времени.
- Внедрил механизм буферизации (batching) данных перед сохранением в ClickHouse, что исключило потери событий при сетевых аномалиях.
- Реализовал API слой с использованием JSON Schema Validation, снизив процент инцидентов деплоя некорректных конфигураций на продуктив на 40%.
- Провел рефакторинг монолитной кодовой базы, изолировав доменную логику в подключаемые Go-модули на основе практик Dependency Injection и Clean Architecture.
- Разработал адаптеры интеграции с внешними SOAP/REST сервисами с использованием Circuit Breaker, предотвращающими каскадные сбои при деградации смежных систем.

**Стек:** Go, ClickHouse, PostgreSQL, RabbitMQ, gRPC, Protocol Buffers, Docker, Kubernetes, Prometheus, Grafana, Clean Architecture.

Таблица демонстрирует, как контекстуализация улучшает восприятие технического опыта.

| Исходный вариант (Слабо) | Оптимизированный вариант (Отлично) |
|---|---|

| Настроил CI/CD и стенды для проверки кода. | Разработал конфигурации GitLab CI/CD пайплайнов с автодеплоем, линтингом и регламентами интеграционного тестирования. |
