Для чего на практике используют ключевое слово defer?

---

Ключевое слово `defer` в Go используют для отложенного выполнения функций. Оно гарантирует, что отложенный вызов будет выполнен перед выходом из текущей функции, независимо от того, как она завершится (даже при `panic` или ошибке парсинга).

### Основные сценарии на практике:

1. **Освобождение ресурсов (Cleanup):**
   - Закрытие файлов (`file.Close()`).
   - Закрытие сетевых или БД соединений (`conn.Close()`).
   - Очистка временных директорий.

   ```go
   f, err := os.Open("file.txt")
   if err != nil {
       // ...
   }
   defer f.Close() // Гарантированно закроет файл
   ```

2. **Синхронизация (Снятие блокировок):**
   - Разблокировка мьютексов в многопоточном коде.

   ```go
   mu.Lock()
   defer mu.Unlock()
   // Критическая секция...
   ```

3. **Обработка паники (Recover):**
   - `defer` — единственное место, где можно вызвать `recover()`, чтобы перехватить панику и не дать приложению упасть.

   ```go
   defer func() {
       if r := recover(); r != nil {
           fmt.Println("Перехватили панику:", r)
       }
   }()
   ```
