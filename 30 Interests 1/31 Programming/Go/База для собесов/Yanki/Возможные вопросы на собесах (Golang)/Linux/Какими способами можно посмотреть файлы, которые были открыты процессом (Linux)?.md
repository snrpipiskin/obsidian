Какими способами можно посмотреть файлы, которые были открыты процессом (Linux)?

---

Есть два основных способа посмотреть открытые файлы процесса по его PID:

1. **Команда `lsof`**
   ```bash
   lsof -p <PID>
   ```
   Показывает список всех открытых файлов указанного процесса.

2. **Файловая система `/proc` (Альтернативный способ)**
   ```bash
   ls -la /proc/<PID>/fd
   ```
   В Linux директория `/proc/<PID>/fd` (file descriptors) содержит символические ссылки на все файлы, открытые данным процессом. Этот способ отлично подходит, если утилита `lsof` не установлена в системе.
